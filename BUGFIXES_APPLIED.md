# Stickies Vault — Current fixes

- Note colors are stored using stable color names and rendered as pastel note cards; legacy hex values are normalized.
- Note editor now stores both rich HTML and plain text so board previews, search, and URLs work after saving/reopening.
- Note cards follow the requested rounded pastel-card design with tags, folder badge, title/content, checklist rows, timestamp, menu and footer status.
- Folder workspace supports create, assign, open, rename and delete; deleting a folder moves its notes to Unfiled.
- Dark mode is persisted globally and applied to the lock screen, notes board, note editor and security settings.
- URLs in saved notes are clickable and offer Open in App / Open in Browser, with the existing remember-choice preference.
- Removed the highlighted Note Editor controls: top Pin, Secret, Favorited, and the Bold/Highlight/Heading toolbar.
